# QuickQR

QuickQR is a modern web application that allows users to convert any URL or text into a QR code instantly. The application provides customization options such as color selection, QR size adjustment, logo placement, and downloading the generated QR code.

The goal of this project is to provide a simple, fast, and user-friendly QR code generator with a clean interface and responsive design.

---

## Live Demo

You can access the live version of the project here:

https://grchetan.github.io/quickqr/

---

## Features

* Generate QR codes from any URL or text
* Instant QR code preview
* Download QR code as PNG
* Customize QR code color
* Adjust QR code size
* Upload a logo inside the QR code
* Dark mode and light mode support
* Fully responsive design for mobile and desktop
* History of recently generated QR codes

## How to Use

1. Open the website using the live link or locally in a browser.
2. Enter a URL or any text in the input field.
3. Click the **Generate QR Code** button.
4. Customize the QR code if required (color, size, logo).
5. Download the generated QR code.
